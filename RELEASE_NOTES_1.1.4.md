## Debra Midi Player 1.1.4

### Overlay & player bar
- **See-through window (Fade)** — under **More** on the player bar, adjust transparency (15–100%) so the whole window lets you see the game behind Debra while keys still play.
- **More panel** — note mapping, Fade slider, and quick timing tweaks (note / chord / modifier ms) without opening Settings.
- Opacity **resets to 100%** each time you launch the app.

### Playback tuning
- **Note mapping modes** — choose how MIDI notes are translated for the game (Settings + More panel).
- **MIDI track picker** — when a file has several tracks, play just one part.
- **Octave ±** — shift the whole song up or down from the player bar.
- **Advanced timing** in Settings — note delay, chord roll, and modifier delay for stubborn timing issues.
- **Cleaner chords** — fewer duplicate / stacked notes when many keys hit at once.

### Help & languages
- **Guided tour** updated (14 steps) for new player features; full help guide refreshed.
- **Localization** — tour, help, and player tooltips completed across all supported languages.

### UI fix
- **Maximized / fullscreen** — sidebar menu shows all entries again, including **Settings** at the bottom.

### Install / update
1. On **v1.1.2+**: use the header **Update** button, or download **DebraMidiPlayer-1.1.4-portable.zip**.
2. Close Debra, extract over your portable folder (`DebraMidiPlayer.exe`, `Assets`, `discord-catalogue.json` together).
3. Run **DebraMidiPlayer.exe** — header shows **v1.1.4**.
