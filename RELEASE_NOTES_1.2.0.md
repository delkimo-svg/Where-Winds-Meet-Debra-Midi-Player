## Debra Midi Player 1.2.0

Major release: **Practice** and **Piano Academy** — learn songs with falling notes, MIDI keyboard feedback, and a real piano sound engine.

### Practice mode (new)
- **Falling-notes piano roll** with a live keyboard strip — Game **36-key** layout or full **88-key** piano view.
- **Follow** and **Learn** modes — play freely, or wait until you press the right note.
- **Practice song library** — import MIDI, search, drag-and-drop, folder refresh (path in Settings).
- **Note labels** on falling notes and keys: letter names (C/D/E), solfège (Do/Ré/Mi), or PC keyboard keys.
- **Right / left hand colors** on the toolbar for split-hand charts.
- **Built-in preview sound** while practicing (separate from keys sent to the game).
- **Guided tour** (? on the Practice toolbar) in all supported languages.

### Piano Academy (Classes)
- **Structured curriculum** for real piano — first module **BB** bundled (exercises + beginner songs).
- **Step-by-step lesson tours** with keyboard highlights and hand diagrams.
- **Learn mode** on exercises — chart pauses until you play the correct notes.
- **Finger numbers** on falling notes during Academy lessons.
- **Progress tracking** — mark lessons complete (saved in settings).
- **Discord curriculum sync** — optional live manifest + lesson MIDI (same bot as the music catalogue).

### MIDI keyboard
- Connect a **MIDI keyboard or digital piano** in Settings → Playback.
- Live input lights the practice keyboard and works in Learn mode and Academy.

### Sound
- **General MIDI piano preview** (MeltySynth + GeneralUser GS soundfont) replaces the old basic synth for practice and Academy listen/preview.

### Portable size
- Portable folder is larger (~126 MB) because the soundfont ships in `Assets\Sounds\`.

### Install / update
1. On **v1.1.2+**: use the header **Update** button, or download **DebraMidiPlayer-1.2.0-portable.zip**.
2. Close Debra, extract over your portable folder (`DebraMidiPlayer.exe`, `Assets`, `discord-catalogue.json` together).
3. Run **DebraMidiPlayer.exe** — header shows **v1.2.0**.
