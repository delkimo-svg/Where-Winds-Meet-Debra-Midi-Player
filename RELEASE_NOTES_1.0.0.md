## Debra Midi Player 1.0.0 — Official release

First stable portable release for **Where Winds Meet**.

### Highlights

- **DebraMidiPlayer.exe** — portable single-file player (no .NET install required)
- **Discord catalogue** — browse and play community MIDI from your server
- **Library, playlists, favorites, history** — full local workflow
- **10 UI languages** — guided tour and help in every supported language
- **Sakura & Wuxia themes** — visual keybind editor matching in-game layout
- **Smart transpose**, auto-play next, global hotkeys (F3–F6 when game is focused)
- **In-app updates** — pulsing Update button when a newer portable build is on Discord

### Install

1. Download **DebraMidiPlayer-1.0.0-portable.rar** from the releases channel.
2. Extract the **entire** archive to a folder (e.g. `C:\Games\DebraMidiPlayer\`).
3. Run **DebraMidiPlayer.exe** from that folder (keep `Assets\` and `discord-catalogue.json` beside it).
4. Accept the Administrator prompt if shown (keyboard input to the game).

### Notes

- Key layout must match your in-game instrument (default: Debra 36 Keys). Use **Settings → Edit key layout** or the keyboard icon in the player bar.
- Catalogue requires `discord-catalogue.json` in the portable folder (included in official builds).
