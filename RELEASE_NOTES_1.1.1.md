## Debra Midi Player 1.1.1

### Updater fix (important)
- **Pulsing Update button** now appears in the **header** (next to Patreon) when v1.1.1+ detects a newer build.
- **v1.0 → v1.1** path: cached Discord credentials are refreshed from `discord-catalogue.json` so the update manifest can be read.

Includes everything from **1.1.0** below.

### Player & playback
- Remappable hotkeys (Settings → Player hotkeys); tooltips show assigned keys.
- Tempo slider improvements + **R** reset to 100%.
- Previous / Next selects and scrolls the track in the correct list.

### Library & catalogue
- Drag & drop `.mid` / `.midi` / folders from Explorer.
- Sort options for Library, Playlist, and Catalogue.
- Green **NEW** badge on recent catalogue tracks.
- Clear library no longer wipes playlists.
- UTF-8 / mojibake text fixes.

### Install / update
1. Download **DebraMidiPlayer-1.1.1-portable.zip**.
2. Close Debra, extract over your folder.
3. Run **DebraMidiPlayer.exe** — header shows **v1.1.1**.

**On v1.0.0:** download this ZIP manually once (the old build has no header Update button). After 1.1.1, future updates use the header **Update** button.
