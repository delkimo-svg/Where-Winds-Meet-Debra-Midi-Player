## Debra Midi Player 1.1.2

### Keyboard templates
- **Saved keybinds now persist** across restarts — custom layouts and edits are no longer reset on launch.
- **Last selected keyboard template** is remembered and restored when you open the player.

**Optional but recommended** for those who use a custom keyboard template (not the default Debra 36 Keys layout).

### Install / update
1. On **v1.1.1+**: use the header **Update** button, or download **DebraMidiPlayer-1.1.2-portable.zip**.
2. Close Debra, extract over your folder.
3. Run **DebraMidiPlayer.exe** — header shows **v1.1.2**.
